# 刘俊威 · 创作桌面预览

独立设计预览，入口为 preview-jordan/；不替换正式首页。

参考 Jordan Delcros（https://www.jordan-delcros.com/）的灰白桌面、立体姓名、物件式作品入口与滚动浏览结构。场景使用本站已有的 Three.js、自有姓名模型和公开项目图片重新搭建，没有复制参考站模型、代码或品牌素材。

三条视频、个人参与说明及数据沿用本站已有公开资料；所列平台数据为 2026-10-29 的历史页面记录，不代表个人独立创作或个人增长成绩。两个工具为科普工作台、动效镜头库。

桌面支持物件点击、键帽反馈、章节导航、暂停动态、视频与工具详情。手机使用独立物件间距；系统减弱动态偏好生效。WebGL 失败时提供普通作品入口。

在仓库根目录运行静态服务器即可本地查看。所有图片、字体和 Three.js 模块均使用本站相对路径。此目录不包含用户私有素材、导出视频或工具运行数据。
