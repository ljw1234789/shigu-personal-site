# 刘俊威 · 创作桌面预览

独立入口为 `preview-jordan/`，不替换正式首页。参考 Jordan Delcros（https://www.jordan-delcros.com/）的桌面构图与场景交互；采用本站自己的姓名模型、视频图像与内容重新实现，不包含原站模型、代码、音频或品牌素材。

## 场景与动效

- 透视相机，桌面从 50° 起按窗口比例调整视野，竖屏为 80°；入场镜头由高处向桌面移动，分批显示姓名、照片与键帽。
- 原生页面滚动驱动带惯性的镜头行进，鼠标位置改变镜头俯仰和偏转。作品由照片、键帽、文字纸页及公开视频中的细节帧组成。
- 照片沿连续的三维轨迹离开桌面、转向镜头；拖动可转动照片，翻面可查看个人参与说明，收起返回原位。浏览、展开和收起共用同一个三维物件，没有项目弹窗或画面副本。
- 播放器使用投影矩阵贴合照片表面；关闭、翻面或滚动离开时移除播放器。平台来源链接保留在展开后的操作栏。
- 两个工具和关于我的纸页也通过场景内展开呈现。导航只是跳转桌面位置，不打开详情窗口。
- 支持系统减弱动态、手动暂停、手机触摸与 WebGL 失败时的普通作品链接。
- 首屏视角同时呈现姓名、首件代表作品和键帽；浏览控件固定在顶部。展开时按整件物件的三维边界计算距离，给标题与底部操作行留出空间。
- 导航只改变原生滚动位置，由相机统一完成平滑过渡；进入后允许立即滚动，关闭浏览器滚动锚定与边界回弹，减少两层动画叠加造成的拖滞。

## 加载和播放

- 本地 `file:` 文件自动打开公开的三维桌面入口，避免浏览器阻止本地 ES Module 后进入旧版页面。入口原生链接保持在当前桌面路径；提前点击时携带进入意图，三维场景初始化后自动进入。模型、字体和图片不再串行阻塞入口；素材请求有超时处理。
- 旧版 `portfolio.html` 在启用脚本时跳转到当前三维桌面，避免旧链接再次展示黑绿版本；它保留的静态内容仅作无脚本阅读后备。主站根目录首页不变。
- 姓名使用相同模型的 gzip 包，体积从 7,002,352 字节降至 2,908,476 字节；解压后字节与原模型完全相同。模型不可用时保留已选中文字标，图片不可用时保留作品文字入口。
- 手机、平板和笔记本电脑分别位于干冰、海岸线和幕后制作的作品区；每件设备有独立的封面、标题、时长与对应视频。点击设备，真实播放器随设备抬起并贴合屏幕，使用屏幕中央的原生播放按钮点播。播放器尝试自动起播，平台拒绝自动播放时仍可手动播放。原生控件与原片链接保留，收回物件时卸载播放器。
- 横向成片使用横屏手机和横向播放器。先确定播放器视口，待设备抬起、屏幕可见后再加载平台页面，避免其在隐藏状态下锁定竖屏布局；播放不依赖暂停桌面动效。平板屏幕比例与播放器匹配，设备屏幕中的画面等比呈现。

## 内容边界

三条视频、个人参与说明及数据沿用本站已有资料。平台数据为 2026-10-29 的历史页面记录，不代表个人独立创作或个人增长成绩。实验、海岸线和幕后细节图均为既有公开成片帧，不是个人工作过程截图。两个工具为科普工作台、动效镜头库。

在仓库根目录运行静态 HTTP 服务器即可预览。所有资源使用本站相对路径；本目录不包含用户私有素材、视频导出或工具运行数据。
