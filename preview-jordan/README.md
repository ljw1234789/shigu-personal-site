# 刘俊威 · 创作桌面预览

主站默认进入 `preview-jordan/` 创作桌面。参考 Jordan Delcros（https://www.jordan-delcros.com/）的桌面构图与场景交互；采用本站自己的姓名模型、视频图像与内容重新实现，不包含原站模型、代码、音频或品牌素材。

## 场景与动效

- 透视相机，桌面从 50° 起按窗口比例调整视野，竖屏为 80°；入场镜头由高处向桌面移动，分批显示姓名、照片与键帽。
- 原生页面滚动驱动带惯性的镜头行进，鼠标位置改变镜头俯仰和偏转。作品由照片、键帽、文字纸页及公开视频中的细节帧组成。
- 照片沿连续的三维轨迹离开桌面、转向镜头；拖动可转动照片，翻面可查看个人参与说明，收起返回原位。浏览、展开和收起共用同一个三维物件，没有项目弹窗或画面副本。
- 原生视频播放器使用投影矩阵贴合照片与设备表面；关闭、翻面或滚动离开时停止音视频并取消媒体请求。平台来源链接保留在展开后的操作栏。
- 两个工具和关于我的纸页也通过场景内展开呈现。导航只是跳转桌面位置，不打开详情窗口。
- 支持系统减弱动态、手动暂停、手机触摸与 WebGL 失败时的普通作品链接。
- 首屏视角呈现姓名和英俊原片卡片；浏览控件固定在顶部。展开时按整件物件的三维边界计算距离，给标题与底部操作行留出空间。
- 导航只改变原生滚动位置，由相机统一完成平滑过渡；进入后允许立即滚动，关闭浏览器滚动锚定与边界回弹，减少两层动画叠加造成的拖滞。

## 加载和播放

- 本地 `file:` 文件自动打开公开的三维桌面入口，避免浏览器阻止本地 ES Module 后进入旧版页面。入口原生链接保持在当前桌面路径；提前点击时携带进入意图，三维场景初始化后自动进入。模型、字体和图片不再串行阻塞入口；素材请求有超时处理。
- 旧版 `portfolio.html` 在启用脚本时跳转到当前三维桌面，避免旧链接再次展示黑绿版本；它保留的静态内容仅作无脚本阅读后备。主站根目录同样进入创作桌面。
- 姓名使用相同模型的 gzip 包，体积从 7,002,352 字节降至 2,908,476 字节；解压后字节与原模型完全相同。模型不可用时保留已选中文字标，图片不可用时保留作品文字入口。
- 手机、平板和笔记本电脑分别位于干冰、海岸线和幕后制作的作品区。点击设备直接请求播放；照片通过“播放成片”启动，均使用同源原生 HTML5 视频，不再依赖抖音嵌入页面的加载、布局及自动播放策略。
- 三条完整公开视频保存为 `media/dry-ice.mp4`、`media/coastline.mp4` 和 `media/behind.mp4`，以 H.264/AAC、720p、faststart 适配静态网站。画面完整等比呈现，不裁掉字幕或原片内容；照片内使用纸色留白。
- 保留封面、原生进度条、音量与全屏。根据真实媒体事件显示加载、缓冲、暂停、播放完毕和错误状态；浏览器拒绝起播时显示播放按钮，加载较慢或失败时提供重新加载及 B 站原片入口。
- 原始公开媒体源来自对应抖音官方播放器中的视频元素，仅用于生成本地网站资源；短期 CDN 地址不写入代码。站点不上传用户私人录屏或剪辑工具导出。

## 内容边界

三条视频、个人参与说明及数据沿用本站已有资料。平台数据为 2026-10-29 的历史页面记录，不代表个人独立创作或个人增长成绩。实验、海岸线和幕后细节图均为既有公开成片帧，不是个人工作过程截图。两个工具为科普工作台、动效镜头库。

在仓库根目录运行静态 HTTP 服务器即可预览。所有资源使用本站相对路径；本目录不包含用户私有素材、私人视频导出或工具运行数据。


## 面试快速阅读与创作资料袋

`#works` 打开独立于 WebGL 的快速阅读，`#work-dry-ice`、`#work-coastline`、`#work-behind` 可直达案例。快速阅读展示已确认的三项具体职责、30 秒成片定位片段、完整视频与来源；不是新剪辑作品或修改前后对照。片段取现有成片截图定位的前 5 秒起，共 30 秒。

默认入口保留创作桌面。首屏有岗位与职责，以及快速阅读入口；照片抬起、翻面、设备播放器、姓名与鼠标保留。纸张简化成三项大字贡献。

`?enter=1&chapter=research` 到创作资料袋：袋盖展开，三张资料页可通过纸张或按钮切换，分别是案例依据、内容研究、选片计划。原 `chapter=practice` 也到此处。`chapter=about` 到个人介绍。桌面有八个章节；英俊公开原片在前，毕导参与项目在后，工具与资料袋随后。

资料袋、快速阅读与旧首页均可下载 `../research/downloads/interview-essentials.zip`。该包是 9 份重点文件与截图的小型集合；完整研究与视频仍在原档案中。研究不冒充个人作品，十条新选片尚未实剪。


## 默认以桌面为主

网站根地址与 `portfolio.html` 默认进入创作桌面，资源就绪后自动入场；快速阅读仅在点选入口或访问 `#works` / `#work-*` 时打开。原长页移到根目录 `overview.html`，由桌面的“阅读版总览”进入。分享按钮统一复制主站地址。旧的作品、工具、研究与经历锚点会导向对应桌面章节；明确的快速阅读锚点仍保留。


## 桌面上的英俊原片

新增三张可直接播放的竖版研究卡：实况拼图教程、vivo 冬日礼盒开箱、CES 国产科技盘点。图片从已有原片提取，媒体复用既有 GitHub Release 的 H.264/AAC 副本。点开卡片即请求播放，沿用场景内抬起、等比贴合、关闭停止与错误重试。标为公开原片研究，不作为刘俊威参与作品或已完成的重剪。

导航可跳到三条卡片；`chapter=yingjun` 与三个 `chapter=yingjun-*` 保留。桌面端将三张竖版卡收成一组，放大并配蓝色底页和研究提要；手机端改用紧凑错落纵排。毕导三组从 16.95、30.2、44 开始，工具在 59，资料袋在 74，个人介绍在 84；英俊仍排在毕导之前。

顶部常驻“英俊视频 03”按钮，直接定位三张可播放卡片；手机端该入口位于左下角，避开顶部导航。

快速阅读和 WebGL 后备页也按英俊在前、毕导在后排列；保留原片研究与个人参与项目的标签。

这一轮压缩英俊与毕导之间的间隔，总滚动轨迹缩短 1200 像素。底页与提要只在桌面显示；原片仍按完整 9:16 播放，卡片可独立点开、收回。


## 起播、个人介绍与联系方式

三条英俊展示视频默认使用同站点 `media/stream/yingjun-*.mp4`：432×768、H.264/AAC、25fps、1 秒关键帧间隔、MP4 索引前置。它们是完整原片的流畅播放副本，清晰原片仍保留在原 GitHub Release；可在播放器里切换，并保留当前位置。具体大小、时长和哈希记录在 `media/stream/manifest.json`。播放器先做少量元数据预热，点击时复用已准备的媒体元素；启用节省流量时跳过预热。

姓名模型仅在接近末尾时请求，首屏移除约 2.9 MB 模型预加载；姓名、简介、微信号收在末尾联系卡，支持复制。毕导项目在封面与展开操作区直接显示已确认参与环节；英俊继续明确标为原片研究。
