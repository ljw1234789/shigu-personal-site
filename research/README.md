# 内容研究档案

本目录是既有个人网站的子模块，沿用蓝白阅读配色，入口接在正式首页导航、三维桌面导航及关于我的展开操作中。原有三条站内视频及桌面交互保留。

## 资料与覆盖

- 英俊姐妹日记：74 条目录、研究总册与全部关联正文、跨平台补证、两版机器转写、画面/字幕校核、人物公司商业线索、方法与拍剪应用。
- 本轮选片：英俊与毕导各 5 条，10 张页面截图、30 张原片抽样画面、环境参考、来源与重剪方案。整个选片目录都在覆盖清单中。
- 毕导：完整报告的全部 dist 资源、关联 research 文件、原提交包、10 条历史采样 CSV/JSON。
- 既有参与作品：project-evidence.js、portfolio-narrative.js 与 2026-10-14 历史数据单独归档；网页另呈现 2026-10-29 三条作品的结构分析与平台数据。历史数字不相互覆盖。

`coverage.json` 与 `downloads/source-coverage.csv` 逐项记录来源相对路径、所属模块、原文件 SHA256、发布地址及排除原因。软件依赖、缓存、运行日志及编译模型不发布。公开页面的临时签名被移除；正文保留日期、未核事项与职责边界。

`catalog.json` 提供全文文档入口；`evidence-index.json` 提供全部图像与媒体记录。JSON 在传输中压缩排版，阅读器可展开表格、分页与查看完整格式化内容。原始资料包保留源排版和原图。网页图为相同像素尺寸的 WebP 副本。

## 媒体与下载

当前三条作品继续使用 `../preview-jordan/media/` 的同源视频。74 条既有公开原片研究副本使用同一仓库的 `research-20261103` 资料 Release，逐条接入原生 video。原有 32 条为 H.264，42 条 HEVC 另制同尺寸 H.264 网页副本，音轨与时长保留；原始 HEVC 保留在媒体资料包。覆盖清单另记转码副本 SHA256 与大小。没有上传私人录屏、剪辑工程导出或登录凭证。

研究原文/原图包及原片/原声包存于该资料 Release；选片包、毕导资料包、原提交包与覆盖表在本目录下载。下载页面显示文件大小。Release 的资产名称和大小须完成验证，发布后再核验公开范围请求及网页播放。

## 重建

在仓库根目录运行 `python3 scripts/build-research-library.py`，再用工作区 Node 运行 `scripts/build-research-images.mjs`。源资料与 Release 待上传包位于脚本所列的本机绝对路径；它们不作为运行时接口。

本网站为静态 GitHub Pages，根目录 `.nojekyll` 保证研究数据按原文件提供。站点图像按需载入，证据目录及全文原始数据按需请求。

## 事实边界

结构研究、机器转写、间隔截图和回图纠错不等于完整连续视听或原声逐句听审；后两者仍未完成。新增十条尚未重剪，不作为个人已完成作品。研究判断、团队传播结果和用户已确认的个人职责分别表述，品牌标签不当作付费证明。
