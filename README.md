# 刘俊威的个人网站

A small, responsive Chinese-language personal homepage built with plain HTML, CSS, and JavaScript.

## Run locally

Serve this directory with a static HTTP server, for example `python3 -m http.server 4191`.

## Deploy with GitHub Pages

Push the repository to GitHub, then open **Settings → Pages** and select **Deploy from a branch**, `main`, and `/ (root)`.

## 创作工具箱

`tools.html` 是六个小工具的统一入口，`tool-catalog.js` 维护公开介绍和访问地址。首页共用同一份目录，旧 `workbench.html` 跳转到新工作台。

- 在线嵌入：科普工作台、动效镜头库、取景（真实 AI 点评仍需本机助手）。
- 拾片：嵌入线上预览，提供 Mac 下载与本机入口。
- 剪辑助手、声样：只提供本机工具入口，不在公共网页中连接本机 API。
- 工具切换保留已打开的页面；「独立打开」使用各工具原地址，便于使用原来的浏览器记录和登录状态。
- 只发布静态页面及公开元数据。不要提交账号配置、声音样本、用户素材、生成记录、`data/` 或 `exports/`。

## 3D 创作世界（2026-10-21）

独立 3D 世界基于 [Bruno Simon / folio-2025](https://github.com/brunosimon/folio-2025) 开源原作改编，直接保留原版模型、配色、材质、光照、开场和车辆物理，按要求复现原站视觉。

- `world/index.html`：独立 3D 世界入口。
- `world/`：构建后的 3D 程序与公开场景素材。
- `world-source/`：可维护源码、依赖版本及构建说明。
- `portfolio.html`：完整平面作品集，含视频、职责、公开数据。
- `tools.html` / `tool-catalog.js`：六个工具的统一入口与公开目录。
- 地面姓名已替换为刘俊威；项目展台为三条参与的科普视频；工具展台为六个创作工具。
- 原作采用 MIT 许可，保留 `world/BRUNO-LICENSE.md`；音乐为 Kounine 的 CC0 作品，保留相应许可。菜单「关于网站」有完整署名。
- 原版服务器和 Google 统计已关闭。姓名、作品和工具元数据为用户内容；3D 世界原作归 Bruno Simon。
- 旧 `island.js` / `island.css` 为上一版历史代码，现首页不再加载。
- 必须使用 HTTP 静态服务器预览，不能通过 file:// 直接运行模块。

## 工具内页主题（2026-10-22）

工具箱使用原场景背景、深紫窗口、顶部方形页签与暖橙按钮。`tool-world.css` 仅作用于工具入口和工作区。各工具自己的 `world-theme.css` 统一操作页面颜色；保留原本的功能、媒体画面与数据存储。声样的服务使用已有 `style.css` 路由加载主题，保持原 CSP。

专注模式收起外围导航，返回全部工具后自动退出。场景动态可以暂停，系统减弱动态偏好默认生效。


## 个人创作桌面（2026-10-22）

公开首页改为桌面与多窗口交互，结构参考 Sharlene Yap 的个人桌面，暖橙场景和深紫窗口延续 Bruno Simon 原作视觉。

- `index.html` / `desktop.css` / `desktop.js`：无构建的首页、原创 SVG 立体图标、窗口管理与内容。
- 介绍、三条参与项目、公开数据、工作经历、六个创作工具都在独立窗口中打开。
- 桌面支持拖动、调整尺寸、最大化、最小化、关闭和任务栏恢复；手机使用适合触控的整页窗口。
- 支持 `#about`、`#projects`、`#tools`、`#experience`、`#tool-science` 等直达链接；旧 `#cases` 仍映射到作品。
- 在线工具延迟到打开窗口时加载；本机工具仅在用户点击时打开本机地址，不探测本机服务。
- 公开互动数据沿用 2026-10-14 的历史快照，保留日期。本人内容来自原作品集，不新增未确认的履历。
- 原 3D 世界保留在 `world/index.html`。背景使用已有场景截图，动效为视差、光尘、图标与窗口过渡；首页不加载 3D 引擎。
- 声音默认关闭；系统减弱动态偏好生效，桌面动态也可手动暂停。作品播放器最小化时会关闭，避免后台播放。
- 六个工具的业务页面、私有文件、导出记录不受桌面改版影响。原 GitHub Pages 网址保持不变。

## 黑白灰桌面与入场（2026-10-27）

- 首页及其窗口、SVG 图标、场景背景使用黑白灰，保留原桌面布局和所有入口。作品照片、视频和外部工具内容仍使用原素材。
- `entrance.css` / `entrance.js` 参考 Onda Studio 首页的入场顺序：姓名淡入 1.2 秒，两行介绍在 1.7 / 1.9 秒错开出现，4.9 秒开始向上退场，5.5 秒结束。
- 每个标签页会话首次进入首页播放；直达内容的 hash 链接、系统减弱动态模式直接打开页面。支持跳过按钮与 Escape；脚本异常有超时退出。
- 入场期间锁定背景交互，结束后释放；入场脚本与窗口管理独立，不加载动画库或参考站资源。

### 四季主题补充

- 开场保持黑白灰；进入后，背景、窗口、文字与 SVG 图标按春绿、夏蓝、秋橙、冬雪整体换色。
- 春季浅绿与花瓣，夏季暖阳与海浪，秋季暖橙与落叶，冬季白雪、浅色窗口与飘雪。季节元素均位于桌面内容后方。
- `seasons.css` / `seasons.js` 控制主题。首次按当前月份选择季节，每 22 秒轮换，颜色用 5 秒过渡。
- 顶栏季节按钮可手动选择、开关自动轮换，选择仅保存到本机。手动选季节后暂停轮换。
- 页面切到后台、桌面动态暂停或系统开启减弱动态时停止自动轮换；作品媒体和工具 iframe 不套颜色滤镜。
